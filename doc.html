API 文档

本项目的 API 端点、请求/响应格式以及认证机制等详细信息。所有API请求均需要进行签名验证，确保数据传输安全。

API 基础URL: https://api.example.com

所有请求都需要包含以下公共参数：

  • merchant_id - 商户ID
  • timestamp - 请求时间戳（10位）
  • sign - 请求签名
  • version - API版本号，默认为v1

签名算法

所有API请求都需要进行签名验证，签名算法如下：

1. 将所有请求参数按参数名ASCII码从小到大排序
2. 使用URL键值对的格式拼接成字符串stringA
3. 在stringA最后拼接上key=商户密钥
4. 对stringA进行MD5运算，得到sign值

安全要求

  • 所有API请求必须通过HTTPS协议传输
  • 敏感数据必须加密传输
  • 每个请求必须包含时间戳参数，服务器会验证请求时间有效性
  • 每个商户必须妥善保管自己的API密钥

创建支付订单

try {
    // 创建支付订单
    double amount = 100.00; // 金额，单位元
    String currency = "CNY"; // 货币类型
    String description = "测试商品"; // 订单描述
    String notifyUrl = "https://your-domain.com/notify"; // 支付结果通知URL
    
    // 可选参数
    Map<String, Object> extra = new HashMap<>();
    extra.put("return_url", "https://your-domain.com/return"); // 支付完成后跳转URL
    extra.put("out_trade_no", "ORDER" + System.currentTimeMillis()); // 商户订单号
    
    Map<String, Object> result = sdk.createPayment(amount, currency, description, notifyUrl, extra);
    
    if (result.get("code").equals(200)) {
        // 支付订单创建成功
        Map<String, Object> data = (Map<String, Object>) result.get("data");
        String orderId = (String) data.get("order_id");

        System.out.println("订单创建成功，订单ID：" + orderId);
        System.out.println("支付URL：" + paymentUrl);
    } else {
        // 处理错误
        System.out.println("创建支付订单失败：" + result.get("message"));
    }
} catch (Exception e) {
    e.printStackTrace();
}

验证回调通知

// 在您的Web控制器中处理回调通知
@RequestMapping("/notify")
public String handleNotify(HttpServletRequest request) {
    try {
        // 获取回调参数
        Map<String, Object> params = new HashMap<>();
        Map<String, String[]> requestParams = request.getParameterMap();
        for (String key : requestParams.keySet()) {
            String[] values = requestParams.get(key);
            params.put(key, values[0]);
        }
        
        // 验证签名
        if (sdk.verifyCallback(params)) {
            // 签名验证通过，处理业务逻辑
            String orderId = (String) params.get("order_id");
            String status = (String) params.get("status");
            
            if ("success".equals(status)) {
                // 支付成功，更新订单状态
                // ...
                return "success"; // 向支付系统返回成功接收
            } else {
                // 支付失败
                // ...
                return "success"; // 向支付系统返回成功接收
            }
        } else {
            // 签名验证失败
            return "fail";
        }
    } catch (Exception e) {
        e.printStackTrace();
        return "fail";
    }
}

        if (sdk.verifyCallback(params)) {
            // 签名验证通过，处理业务逻辑

            } else {
