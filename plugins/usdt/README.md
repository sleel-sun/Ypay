# USDT支付插件

## 简介

本插件基于Epusdt平台开发，支持USDT加密货币支付，支持TRC20和ERC20网络。

## 安装说明

1. 将插件文件夹上传到网站的 `/plugins/` 目录下
2. 登录网站管理后台，进入「支付插件」页面
3. 找到「USDT支付」插件，点击「安装」
4. 安装完成后，点击「设置」进行参数配置

## 配置参数说明

- **API接口地址**：Epusdt平台的API接口地址，必须以http://或https://开头，以/结尾
- **商户ID**：Epusdt平台分配的商户ID
- **商户密钥**：Epusdt平台分配的商户密钥
- **支付网络**：选择TRC20或ERC20网络

## 使用说明

1. 配置好插件参数后，在「支付通道」中添加新的支付通道
2. 选择「USDT支付」作为支付方式
3. 填写通道名称、手续费等信息
4. 保存后即可在前台使用USDT支付

## 注意事项

1. 使用前请确保已在Epusdt平台注册并获取相关参数
2. TRC20网络手续费较低，推荐优先使用
3. 请确保API接口地址可以正常访问
4. 如遇支付问题，请检查Epusdt平台的日志记录
