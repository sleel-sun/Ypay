# 拉卡拉支付插件

## 插件说明

本插件用于对接拉卡拉支付网关，支持支付宝、微信等多种支付方式。

## 配置说明

1. 商户编码(partner_code)：由4-6位大写字母或数字构成，在拉卡拉支付后台获取
2. 商户密钥：用于签名验证，在拉卡拉支付后台获取

## 支持的支付方式

- Alipay支付
- Alipay+支付
- Wechat支付

## 接口说明

本插件实现了以下接口：

1. 支付下单接口：生成支付二维码或跳转支付页面
2. 支付回调接口：接收支付结果通知
3. 支付结果页面：显示支付结果

## 使用方法

1. 在支付系统后台添加支付通道，选择「拉卡拉支付」
2. 填写商户编码和商户密钥
3. 选择需要开启的支付方式
4. 设置费率和限额
5. 保存配置

## 注意事项

1. 确保服务器能够正常访问拉卡拉支付API
2. 确保回调地址能够被拉卡拉支付服务器访问
3. 测试支付时，建议使用小额测试

## 常见问题

1. 支付失败：检查商户编码和密钥是否正确
2. 回调失败：检查服务器是否能被外网访问，防火墙是否开放
3. 签名错误：检查密钥是否正确，签名算法是否一致
